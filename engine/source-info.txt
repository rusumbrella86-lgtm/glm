The unmodified WebAssembly binary and its generated JavaScript were obtained
from https://powdertoy.co.uk/wasm/powder.wasm and powder.js on 2026-09-08.
The C++ physics simulation has not been modified.

Astropowder modifies the generated JavaScript only to:
1. Install a local Lua bridge after the in-browser filesystem has initialized.
2. Route native keyboard events to the engine canvas, preserving web form input.
3. Preserve WebGL drawing buffers for the presentation renderer.
4. Preserve the Astropowder page title.

The readable bridge is at /engine/bridge.lua. It exposes the engine's real
materials and wall tools and connects drawing, simulation controls and saves.
The original element colours for a small group of natural materials are adjusted
for presentation. The optional cinematic pass adds display shading and texture;
it does not change particle interactions, resolution or physical accuracy.

The Astropowder interface, engine adapter, cinematic shader and build files are
also distributed under GPL-3.0. Download: /astropowder-source.zip
Reproduce the build with Node.js 22.13+ and npm: npm ci && npm run build.
